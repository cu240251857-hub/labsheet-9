# Campus Student Course Registration System

A complete ready-to-run full-stack Student Course Registration System.

## Stack
- Frontend: HTML5, CSS3, Vanilla JavaScript
- Backend: Node.js + Express
- Database: SQLite using Node's built-in `node:sqlite`
- REST API between frontend and backend

## Requirements
Node.js 22.5+.

## Run
```bash
npm install
npm run init-db
npm start
```

Open:
http://localhost:3000

## API
GET /api/health
GET /api/courses
GET /api/students
GET /api/stats
POST /api/register
